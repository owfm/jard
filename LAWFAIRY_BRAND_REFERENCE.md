# LawFairy — Brand Reference for Development

> This document distils the LawFairy Brand System V0.1 into an actionable reference for building a Next.js / React website. Treat every value here as a hard constraint unless a deviation is explicitly approved by the design team.

---

## 1. Brand Identity

**Tagline:** "Trusted Legal Intelligence"

**Essence:** Transforming legal and HR tasks into intelligent, structured and compliant workflows. A scalable, explainable alternative to generic AI and manual legal processes for SMEs.

**Four Pillars:**

1. **Trust & Accuracy** — No hallucinations, no black-box AI. Every output is fact-checked and regulation-ready.
2. **Structured Workflows** — From onboarding to compliance, every process uses reusable data.
3. **Explainable Intelligence** — Every decision and document can be explained, traced and verified.
4. **SME Empowerment** — Built for growth; SMEs save hours weekly and scale without legal bottlenecks.

**Sub-brands / Product names:**

| Name | Role |
|---|---|
| FairyLogic™ | The core engine |
| FairyDraft™ | Document product |
| FairyFlow™ | Workflow product |
| FairyTrust™ | Brand promise |
| The Legal Intelligence Hub | Content arm |

## 2. Tone of Voice

All copy — UI labels, marketing pages, error messages, tooltips — should follow these five principles:

| Principle | Guidance |
|---|---|
| **Confident** | Speak like experts, never arrogant. |
| **Clear** | Plain English over legalese or AI hype. |
| **Creative** | Think differently, unlock possibility, avoid unnecessary formality. |
| **Supportive** | Empower and reassure users, never intimidate. |
| **Intelligent** | Always structured, always explainable. |

Preferred phrasing style: direct, second-person ("You can…", "Your contract…"), active voice, short sentences. Avoid jargon, avoid hype words like "revolutionary" or "game-changing".

## 3. Colour Palette

### 3.1 Core Colours

| Name | Hex (100%) | Hex (80% tint) | Hex (60% tint) | Role |
|---|---|---|---|---|
| **Off-white** | `#e7e3d9` | `#ebe8e0` | `#f0eee8` | Primary background, neutral base |
| **Mint** | `#bfdbcc` | `#cbe2d6` | `#d8e9e0` | Secondary background, calm accent |
| **Tangerine** | `#ff642c` | `#ff8356` | `#ffa280` | Primary action colour, CTAs |
| **Honey** | `#ffa426` | `#ffb651` | `#ffc87c` | Warm accent, highlights |
| **Chocolate** | `#461c17` | `#6b4945` | `#907673` | Primary text colour, dark UI |
| **Teal** | `#09a0ad` | `#3ab3bd` | `#6bc6cd` | Trust accent, links, secondary actions |

Tints are generated by blending 20% and 40% white into the base colour respectively.

Black (`#000000`) and white (`#ffffff`) are also available as utility colours but are excluded from the ratio system.

### 3.2 Colour Ratio

Apply these proportions across any page or campaign (excluding black, white, and imagery):

| Colour | Target ratio |
|---|---|
| Off-white | 40% |
| Mint | 20% |
| Tangerine | 15% |
| Honey | 10% |
| Chocolate | 7.5% |
| Teal | 7.5% |

In practice this means: off-white dominates backgrounds, mint provides secondary surface areas, tangerine is used sparingly for high-impact moments (buttons, key headings), honey for supporting warmth, and chocolate + teal appear in text and small accents.

### 3.3 Gradient

The "freedom gradient" blends brand colours in this order for dynamic backgrounds:

```
Off-white → Mint → Teal → Tangerine → Honey
```

Use for hero sections or feature backgrounds. Keep text on gradient areas large and high-contrast.

### 3.4 Accessibility (WCAG 2.1 Level AA)

All colour pairings have been verified. Key contrast ratios with **Chocolate** as text colour:

| Foreground | Background | Ratio | AA Normal | AA Large |
|---|---|---|---|---|
| Chocolate | Off-white | 11.39:1 | ✓ | ✓ |
| Chocolate | Mint | 9.88:1 | ✓ | ✓ |
| Off-white | Chocolate | 11.39:1 | ✓ | ✓ |
| Mint | Chocolate | 9.88:1 | ✓ | ✓ |
| Tangerine | Chocolate | 4.94:1 | ✓ | ✓ |
| Honey | Chocolate | 7.36:1 | ✓ | ✓ |
| Teal | Chocolate | 4.62:1 | ✓ | ✓ |

**Rules:**

- Body text must always be Chocolate on Off-white or Mint (or the reverse for dark sections).
- Tangerine and Honey should not be used as background colours for small body text — they work for large headings and buttons where the text is Chocolate.
- Teal on Chocolate only passes for large text (≥18pt regular or ≥14pt bold). Do not use for body copy.

## 4. Typography

### 4.1 Typefaces

| Role | Typeface | Weight | Usage |
|---|---|---|---|
| Headlines | Freight Text | Medium (400) | Hero headings, section titles, dramatic statements |
| Headline emphasis | Freight Text | Medium Italic | Emphasis within headlines |
| Sub-headings | Neulis Sans | Medium (500) | Section sub-heads, card titles, nav labels |
| Body copy | Neulis Sans | Light (300) | All running text, UI labels, form fields |

**Font sources:** Both typefaces are available via Adobe Fonts.

- Freight Text: `fonts.adobe.com/fonts/freight-text`
- Neulis Sans: `fonts.adobe.com/fonts/neulis-sans`

### 4.2 Typesetting Rules

**Freight Text (headlines):**

- `line-height`: 1.0 (100% of font size) — or slightly more, never less.
- `letter-spacing`: 0
- Use sparingly. Any copy longer than three sentences must switch to Neulis Sans.

**Neulis Sans (body / sub-heads):**

- `line-height`: 1.2 (120% of font size) — or slightly more, never less.
- `letter-spacing`: 0

### 4.3 Suggested Type Scale (for web)

These are recommendations based on the brand system's proportions — adapt to your responsive breakpoints:

| Element | Mobile | Desktop | Font | Weight |
|---|---|---|---|---|
| Hero heading | 2rem (32px) | 3.5rem (56px) | Freight Text | Medium |
| Section heading | 1.75rem (28px) | 2.5rem (40px) | Freight Text | Medium |
| Sub-heading | 1.125rem (18px) | 1.25rem (20px) | Neulis Sans | Medium |
| Body | 1rem (16px) | 1rem (16px) | Neulis Sans | Light |
| Small / caption | 0.875rem (14px) | 0.875rem (14px) | Neulis Sans | Light |
| Button label | 1rem (16px) | 1rem (16px) | Neulis Sans | Medium |

### 4.4 Fallback Font Stacks

```css
--font-headline: "freight-text-pro", "Georgia", "Times New Roman", serif;
--font-body: "neulis-sans", "Inter", "Helvetica Neue", Arial, sans-serif;
```

## 6. Brand Elements

### 6.1 Logo

- Primary logo: wordmark "LawFairy" with wing icon to the left.
- Minimum width: **60px**.
- Clear space: one "x" unit (the width of the wing icon) on all sides.
- Available in all brand colours plus mono black and mono white.
- An animated version exists for loading states or hero moments.

### 6.2 Brand Icon (standalone wings)

- Minimum width: **10px**.
- Same clear-space rules as the full logo.
- Use as favicon, app icon, or compact identity mark.

### 6.3 Geometric Pattern

A repeating pattern inspired by wing shapes and leaf motifs, rendered in Teal on Mint (or other brand-colour combinations). Use as:

- Background texture for sections that need visual relief from block colour.
- Subtle overlay on hero images.
- Card or panel backgrounds at reduced opacity.

### 6.4 Illustrations

Four hero illustrations represent the brand pillars (Trust & Accuracy, Structured Workflows, Explainable Intelligence, SME Empowerment). They use the full colour palette with geometric shapes and diverse human figures. Use these on feature pages, empty states, and marketing sections.

## 7. Layout & Spacing

### 7.1 UX Grid

The brand system specifies simple grids and spacing for consistency. Recommended implementation:

- **Max content width:** 1200px (centred).
- **Grid:** 12-column with 24px gutters (desktop), 16px gutters (mobile).
- **Section padding:** 80px vertical (desktop), 48px (mobile).
- **Component spacing:** Use an 8px base unit. Common increments: 8, 16, 24, 32, 48, 64, 80.

### 7.2 Buttons

Based on the UX page, buttons follow these patterns:

- **Primary:** Tangerine background, Chocolate text, rounded corners.
- **Secondary:** Outlined in Chocolate, transparent background.
- **Padding:** Generous horizontal padding (~24px horizontal, ~12px vertical).
- **Border radius:** Small, consistent — approximately 6–8px.

### 7.3 Cards & Panels

- Use Off-white or Mint as card backgrounds.
- Subtle border or shadow to separate from page background.
- Consistent internal padding (24px).

## 10. Implementation Checklist

When building pages, verify these requirements:

- [ ] Off-white is the dominant surface colour (~40% of non-image area).
- [ ] Body text is Chocolate on light backgrounds (Off-white or Mint).
- [ ] Tangerine is reserved for primary CTAs and key accent moments — not overused.
- [ ] Teal is used for links and secondary interactive elements.
- [ ] Headlines use Freight Text; everything else uses Neulis Sans.
- [ ] Freight Text never appears in blocks longer than three sentences.
- [ ] Line-height is ≥1.0 for headlines, ≥1.2 for body.
- [ ] Letter-spacing is 0 for both typefaces.
- [ ] All text/background combinations meet WCAG 2.1 AA (4.5:1 for normal text, 3:1 for large text).
- [ ] Logo has the required clear space (1× wing-icon width on all sides).
- [ ] Logo minimum width of 60px is respected; icon minimum width of 10px.
- [ ] Brand pattern and illustrations are used to break up block-colour sections.
- [ ] The gradient (off-white → mint → teal → tangerine → honey) is used for hero/feature backgrounds, not arbitrary colour blends.
- [ ] Icons display at ≥15px.
- [ ] Tone of voice is confident, clear, creative, supportive, and intelligent throughout.
